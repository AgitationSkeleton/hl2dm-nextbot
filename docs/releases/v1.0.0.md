First public release: server bots for Half-Life 2: Deathmatch, using the Valve HL2MP NextBot that ships in the current HL2DM `server.dll`, as a Metamod:Source addon (Windows).

### Highlights
- Fill-style population: `hl2mpnb_quota` keeps N players in the game and humans replace bots, in deathmatch and teamplay (Valve's own quota cannot count deathmatch players).
- Bots path on the nav mesh, pick up and use map weapons (SMG, shotgun, AR2, .357, crossbow, RPG, crowbar, stunstick), throw props with the gravity gun, and go for health and ammo.
- Fixes for stock bugs: a gravity-gun aiming crash, bots never seeking ammo, `hl2mp_bot_add` model/name bugs, and teamplay bots all joining one team. Each fix is found by byte pattern and switches itself off with a log line if a game update changes the code.
- `hl2mpnb_nav_generate`: the game's nav generator with corrections for DM maps (seeds at every spawn and pickup, player-clip mask, solid props and toggle brushes).
- Nav meshes for the eight stock maps (`hl2dm-nextbot-navmeshes-stock.zip`).
- Built-in names: the stock TF2 bot names; `bot_names.txt` overrides them.

### Known gaps
- No behavior seeks armor (bots pick up batteries they walk over).
- Bots lose time in small rooms full of movable props.
- Kill rates are low on large teamplay maps with few bots.
- Custom maps need a nav mesh generated on a test server first.
